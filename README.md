# Freight Trucking App

Aplikacion Angular (frontend) për menaxhimin e transportit të mallrave: gjurmim dërgesash, planifikim ngarkesash, caktim transportuesish, regjistrim automjetesh dhe vendndodhjesh biznesi. Demoja web është simulim statik funksional — panel me statistika, gjurmim dërgese me status, listë dërgesash, planifikim ngarkese, transportues dhe automjete (mock data).
